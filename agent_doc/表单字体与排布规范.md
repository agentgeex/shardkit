# 表单字体与排布规范

> 适用：所有表单/筛选/编辑页（框架内与 copy-in 下游产品）
> 参考实现：`/form`（表单 · 全部示例）｜`src/pages/cases/form-all.tsx`
> 维护：win_ui_lead｜建立：2026-10-20

---

## 1. 一句话

**字段标签与输入框内容同字号（14px），层级只靠字重区分（标签 500 / 输入框 400）。**
不要靠「谁字大」来区分标签和内容 —— 一旦做大做小就会显得"反了"。

---

## 2. 字体规范（锁定值）

| 元素 | 类名 | 实渲染 |
|---|---|---|
| 页面/区块标题（`CardTitle`） | `text-base font-semibold` | 16px / 600 |
| **字段标签（`Label`）** | **`text-sm font-medium`** | **14px / 500** |
| **输入框内容（`Input`）** | **`text-sm`** | **14px / 400** |
| 占位符（placeholder） | `placeholder:text-muted-foreground` | 14px / 400 灰 |
| 标签下提示（hint） | `text-[11px] leading-snug text-muted-foreground` | 11px 灰 |
| 字段错误（error） | `text-xs text-destructive` | 12px 红 |
| 页面大标题（`PageHeader`） | `text-title`（令牌） | 22px |

> 字阶令牌见 [`设计令牌与配色说明.md`](./设计令牌与配色说明.md)。

### 为什么标签不是"标题"

表单标签是**控件名**，不是标题。它比输入内容**只重一点、不更大**：
- 标签更大 → 视觉上抢过内容，页面像一堆小标题；
- 输入框更大/更粗 → 内容像被加粗强调，脏。

---

## 3. 排布规范（左右式）

| 规则 | 值 |
|---|---|
| 布局 | 标签左、控件右：`grid sm:grid-cols-[8em_1fr]` |
| 标签对齐 | **右对齐**（同列标签右边界成一条竖线） |
| 标签列宽 | 固定 `8em`（≈128px，约 8 个汉字不换行） |
| 标签↔控件间距 | `gap-3`（12px） |
| 必填星 | `*` 在标签文字**左侧**（`::before`），不影响右对齐 |
| 窄屏（< 640px） | 自动降级为**标签在上、控件在下** |

## 4. 标准写法（直接用原语，别手搓）

```tsx
import { FormRow, FormGrid, FormField } from "@/components/ui/form-field";

// 行式：一行一个字段
<FormRow label="文本输入" htmlFor="f-text" hint="基础文本；带清除按钮">
  <Input id="f-text" placeholder="请输入" />
</FormRow>

// 栅格：一行 1/2/3 个字段
<FormGrid cols={2}>
  <FormField label="公司全称" htmlFor="c-name">
    <Input id="c-name" />
  </FormField>
  <FormField label="企业简称" htmlFor="c-code" required>
    <Input id="c-code" />
  </FormField>
</FormGrid>
```

用原语即自动满足：字号、字重、右对齐、列宽、间距、必填星、窄屏降级。

## 5. 常见错误对照

### ❌ 1. 把标签和输入框字体弄反（最常见）

```tsx
<Label className="text-lg">产品名称</Label>      {/* ✗ 标签 18px，比内容还大 */}
<Input className="text-xs" />                     {/* ✗ 内容 12px，比标签还小 */}
```

✅ 正确：
```tsx
<Label className="text-sm font-medium">产品名称</Label>
<Input />   {/* 自带 text-sm */}
```

### ❌ 2. 给输入框加粗或放大

```tsx
<Input className="text-base font-medium" />   {/* ✗ 内容被强调，整页发脏 */}
```
✅ 输入框**不要**加 `text-base` / `text-lg` / `font-medium`；默认即可。

### ❌ 3. 标签左对齐 + 自动列宽

```tsx
<div className="flex gap-2"><Label>名称</Label><Input /></div>   {/* ✗ 各字段输入框起点参差 */}
```
✅ 用 `FormRow` / `FormGrid`，列宽固定 `8em`、标签右对齐。

### ❌ 4. 用 `space-y-*` 排字段

```tsx
<div className="space-y-3">   {/* ✗ 项目规范禁用（flex 换行会失效），且不满足成列对齐 */}
```
✅ 用 `FormRow` 的 grid 或 `flex flex-col gap-3`。

## 6. 自检清单

1. 标签 14px/500，输入内容 14px/400 —— **同字号**；
2. 同一区块内所有输入框**左边界对齐**，标签**右边界对齐**；
3. 长标签不换行（`8em` 内放得下）；
4. 必填星在标签左侧；
5. 窄屏切到「上标签下控件」不挤压；
6. `npx tsc -b` = 0；`node scripts/check-ui-rules.mjs` 通过（不得新增原生色板 / `space-*` / `h-screen`）。
