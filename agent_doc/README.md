## 快速结论（若你只有 1 分钟）

- ShardKit = **纯前端 SPA**（React + Refine + Tailwind + shadcn），**copy-in** 消费，**不装成 npm 依赖**。
- 数据当前全是**内存 mock**；生产环境**切 `VITE_API_URL` 指向 BFF**，页面代码**零改动**。
- 服务器端 = **BFF**（建议 **FastAPI** 或 **NestJS**），**前端绝不直连 MySQL/Redis**。
- 改代码必走：`npx tsc --noEmit`（TSC=0）+ `scripts/verify_*.mjs`（ALL PASS）。
