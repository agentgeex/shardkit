# 设计令牌与配色说明（ShardKit 框架级）

> 适用：ShardKit 组件库**及其所有下游产品**（含 agentgeex webtools 等 copy-in 使用方）。
> 定位：这是**框架的配色规范**。各产品可在此基础上做**品牌化覆盖**（见 §6），但**不得**退回写死原生色板。
> 版本：2026-10-16｜维护：win_ui_lead（AGX 前端 UI 负责人）

---

## 1. 一句话原则

**只用语义令牌，不写原生色板。** 组件里出现 `bg-emerald-500` / `text-sky-500` 这类写法即为**缺陷**（暗色主题下对比度失控、状态色各写各的、无法品牌化）。

---

## 2. 颜色令牌

### 2.1 基础语义令牌（shadcn 标准，已就位）

`background / foreground / card / card-foreground / popover / popover-foreground /
primary / primary-foreground / secondary / secondary-foreground / muted / muted-foreground /
accent / accent-foreground / destructive / destructive-foreground / border / input / ring`

用法：`bg-primary text-primary-foreground`、`border-border`、`text-muted-foreground`。
值与 `:root` / `.dark` 双套定义在 `src/index.css`。

### 2.2 ★状态语义令牌（2026-10-16 新增）

| 令牌 | 用途 | 浅色 (`:root`) | 深色 (`.dark`) | 前景 |
|---|---|---|---|---|
| `--success` | 成功 / 在线 / 通过 | `142 71% 45%` | `142 69% 58%` | `--success-foreground` |
| `--warning` | 警告 / 待办 / 风险 | `38 92% 50%` | `38 92% 50%` | `--warning-foreground` |
| `--info` | 提示 / 中性状态 | `199 89% 48%` | `199 89% 60%` | `--info-foreground` |

用法：
```tsx
<Badge variant="success">在线</Badge>          {/* 组件内已封装 */}
<span className="text-success">+20.1%</span>
<div className="border-warning/30 bg-warning/15 text-warning">风险</div>
```
> 状态徽章的「柔和底」约定：`border-{tone}/30 bg-{tone}/15 text-{tone}`（见 `badge.tsx`）。

### 2.3 规则

1. 新代码**禁止**新增 `bg/text/border/ring-<原生色板>-<数字>`；存量**分批**替换（见 §7）。
2. 单视图只保留 **1 个强调色**（通常是 `primary`）。
3. 表面色与 `-foreground` **成对**使用，保证对比度。
4. 图表 / 大色块如需更宽色阶，优先从语义令牌派生（`primary/10`），仍不写原生色板。

---

## 3. 字阶（6 档语义名，2026-10-16 新增）

| 语义名 | 尺寸 | 行高 | 用途 |
|---|---|---|---|
| `text-caption` | 12px | 1rem | 辅助 / 说明 / 时间戳 |
| `text-body` | 14px | 1.5rem | **正文基准** |
| `text-body-lg` | 16px | 1.5rem | 强调正文 / 段落引导 |
| `text-subtitle` | 18px | 1.75rem | 区块标题 |
| `text-title` | 22px | 1.875rem | 页面标题（h1） |
| `text-display` | 28px | 2.25rem | 大标题 / 空态主标 |

> **加法**实现：不改动 Tailwind 默认 `xs/sm/base…`，避免破坏存量。新代码优先用语义名，存量逐步迁移。
> 排版：标题加 `text-balance`，正文加 `text-pretty`（长文折行更整齐）。

---

## 4. 阴影（3 档，2026-10-16 新增）

| 令牌 | 层级 | 用法 |
|---|---|---|
| `shadow-surface` | 静置 | 卡片、面板 |
| `shadow-raised` | 浮起 | 卡片 hover、下拉、悬浮工具条 |
| `shadow-overlay` | 弹层 | Dialog / Popover / Sheet / 大浮层 |

**禁止**散点取用 `shadow-[0_4px_12px_#...]`。已有 `shadow-sm/md/lg` 视为存量，迁移时收敛到 3 档。

---

## 5. 圆角 / z 标尺 / 间距

- **圆角**：`rounded-lg`(= `--radius` 0.6rem) / `md` / `sm` 三档；**禁止**新增 `rounded-[Npx]`。
- **z 标尺**（新增固定档，禁 `z-[999]`）：
  `z-header 30 · z-dropdown 40 · z-overlay 50 · z-modal 60 · z-popover 70 · z-toast 80`
- **间距**：新代码用 `gap-*`，**禁止**新增 `space-x/y-*`（flex 换行时会失效）。

---

## 6. 品牌化与「项目自定义配色」

框架的 `--primary` / `--ring` 目前是**默认蓝**（`221.2 83.2% 53.3%`）。下游产品**按需覆盖**，两种做法：

### 做法 A：改令牌（推荐，最小改动）
在产品的 `:root` / `.dark` 覆写 `--primary` / `--primary-foreground` / `--ring` 三件套即可换主色；其余语义令牌自动跟随。

### 做法 B：tweakcn 出完整 preset
用 https://tweakcn.com 可视化调一套主题（含品牌色 + 明暗双套），导出 JSON → 粘进 `index.css` 的 `:root` / `.dark`。
> 参考：仓库 `agent_doc/` 中其他文档与 `tailwind.config.js` 的 `theme.extend`。

### 给 agentgeex webtools 的建议（本项目）
- webtools 是**管理控制台**，信息密度高 → 主色建议保持冷静蓝或靛（避免高饱和暖色抢占注意力）。
- 状态色统一走 `--success/--warning/--info`，替换现存的 `emerald-500/amber-500/sky-500` 直写。
- 暗色优先：控制台常在暗色下长时间使用，务必核对暗色对比度（`--*-foreground` 已按此设计）。

---

## 7. 存量迁移策略（原生色板 → 语义令牌）

框架自身存量（2026-10-16 基线）：原生色板 **119** 处、`space-*` **89** 处、`z-[N]` **2** 处、`h-screen` **2** 处。
建议按「**组件层 → 页面层**」分两批：

| 批次 | 范围 | 做法 | 预估 |
|---|---|---|---|
| B1 | `src/components/ui/*` | 换成语义令牌（如 Badge 已改） | 小，1–2 天 |
| B2 | `src/pages/**` | 按页面切片替换，跑视觉基线对比 | 中，3–5 天 |

每修一批，跑 `node scripts/check-ui-rules.mjs --update` 把预算数字**下调**（只降不升）。

## 8. 参考：可直接粘贴的配置

**`tailwind.config.js`（节选）**
```js
import tailwindcssAnimate from "tailwindcss-animate";
export default {
  theme: {
    extend: {
      colors: {
        success: { DEFAULT: "hsl(var(--success))", foreground: "hsl(var(--success-foreground))" },
        warning: { DEFAULT: "hsl(var(--warning))", foreground: "hsl(var(--warning-foreground))" },
        info:    { DEFAULT: "hsl(var(--info))",    foreground: "hsl(var(--info-foreground))" },
      },
      fontSize: {
        caption: ["0.75rem", { lineHeight: "1rem" }],
        body: ["0.875rem", { lineHeight: "1.5rem" }],
        "body-lg": ["1rem", { lineHeight: "1.5rem" }],
        subtitle: ["1.125rem", { lineHeight: "1.75rem" }],
        title: ["1.375rem", { lineHeight: "1.875rem" }],
        display: ["1.75rem", { lineHeight: "2.25rem" }],
      },
      boxShadow: {
        surface: "0 1px 2px 0 rgb(0 0 0 / 0.05)",
        raised: "0 4px 12px -2px rgb(0 0 0 / 0.10), 0 2px 4px -2px rgb(0 0 0 / 0.06)",
        overlay: "0 12px 32px -8px rgb(0 0 0 / 0.24), 0 4px 8px -4px rgb(0 0 0 / 0.12)",
      },
      zIndex: { header: "30", dropdown: "40", overlay: "50", modal: "60", popover: "70", toast: "80" },
    },
  },
  plugins: [tailwindcssAnimate], // ★ 点亮 animate-in/out（弹层动效）
};
```

```css
        --warning: 38 92% 50%; --warning-foreground: 26 83% 14%;
        --info: 199 89% 48%; --info-foreground: 0 0% 100%; }
.dark { --success: 142 69% 58%; --success-foreground: 144 61% 12%;
        --warning: 38 92% 50%; --warning-foreground: 26 83% 14%;
        --info: 199 89% 60%; --info-foreground: 202 80% 10%; }

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```
