# 布局与台面层次规范（A / B / C / D 四区）

> 适用：ShardKit 外壳（AppShell）与所有页面
> 参考实现：Element Plus 深色侧栏主题（`localhost:4000` 同款配色）
> 维护：win_ui_lead｜建立：2026-10-20

---

## 1. 一句话

**外壳必须一眼分出四块：深色侧栏 vs 浅色主区。**
主区里「灰画布 + 白卡片」两层次；**卡片底色必须与画布不同**，否则整页发平。

---

## 2. 四区定义

```
┌──────────────┬────────────────────────────────────────┐
│  A 品牌条     │  B 顶栏（含标签栏）                      │
│  aside > a   │  header + TabBar                       │
├──────────────┼────────────────────────────────────────┤
│              │                                        │
│  C 菜单区     │  D 主显示区                             │
│  aside > nav │  main（画布）→ Card（内容面）             │
│              │                                        │
└──────────────┴────────────────────────────────────────┘
```

| 区 | DOM | 底色令牌 |
|---|---|---|
| **A** 品牌条 | `aside > a`（Brand） | `bg-chrome` |
| **B** 顶栏 + 标签栏 | `header` / `[data-testid="tabbar"]` | `bg-card`（白/深面） |
| **C** 菜单区 | `aside` / `aside nav` | `bg-chrome` |
| **D** 主显示区 | `main` | `bg-background`（画布） |
| D 内内容 | `Card` | `bg-card`（内容面） |

| 对比对 | 亮色 | 暗色 |
|---|---|---|
| 侧栏 vs 主区 | **16.25 : 1** | 1.17 : 1 |

## 4. 四条硬规则

1. **侧栏必须是 `bg-chrome`**（深色），不能是 `bg-card` / `bg-background`。
   这是整个布局层次的"锚"——层次感 90% 来自它。
2. **`--card` 与 `--background` 不得同值**。
   同值 = 卡片与画布融合 = 页面发平（本次修复的原始 bug）。
3. **区域分界用 `border-strong`**，不要用 `border`（太淡，1.2:1 看不见）。
4. **外壳层底色必须不透明**。禁止 `bg-card/60`、`bg-card/70` + `backdrop-blur` 充当底色——白叠白等于没有底色。

---

## 5. 反例（本次修复的四个病根）

| # | 反例 | 后果 |
|---|---|---|
| 1 | `--card: 0 0% 100%` 且 `--background: 0 0% 100%` | 卡片与画布 **1.00:1**，完全同色 |
| 2 | `header` 用 `bg-card/60 backdrop-blur-xl` | 半透明白叠白 = 白，模糊无意义 |
| 3 | 全屏三个模糊光斑（`fixed inset-0 -z-10` + `blur-[120px]`） | 整屏糊一层彩雾，所有分区被冲淡 |
| 4 | 菜单选中用 `bg-primary/10 border-primary/30` | 在深色侧栏上几乎看不见；浅色侧栏上也过淡 |
| 5 | 菜单选中整条铺满高饱和亮蓝（`#409EFF`） | 噪音大、像 2018 模板；改用白块反相 |
| 6 | 选中态只靠低透明度底（`bg-white/10`） | 深色侧栏上几乎看不出，等于没有选中 |

✅ 正确做法：
```tsx
<aside className="... border-r border-strong bg-chrome text-chrome-foreground">
<header className="... border-b border-strong bg-card">
<TabBar className="... border-b border-strong bg-card">
<main className="flex-1 overflow-y-auto bg-background p-4 md:p-6">
```

## 6. 写页面时的规矩

1. **页面不要自带底色**（别写 `bg-white` / `bg-slate-50`）。
   底由 `main` 的 `bg-background` 提供，页面只管往里放 `Card`。
2. **内容一律包 `Card`**。
   想要"大框"就再套一层 `Card`，**不要**给 `div` 加 `bg-card` 手搓（会与卡片同色、边界不清）。
3. **分隔线**：卡片内部用 `border`；卡片之间靠 gap + 画布色，别加框。
4. **侧栏里新增控件**，文字用 `text-chrome-foreground`，悬停 `hover:bg-chrome-hover hover:text-white`，选中 `bg-chrome-active text-chrome-active-foreground`。
5. **换品牌色**只改 `--chrome` / `--chrome-active`，不要逐处改 class。

## 7. 校验

```bash
node scripts/verify_surfaces.mjs     # 期望末行 ALL PASS
npx tsc -b                           # 期望 TSC=0
node scripts/check-ui-rules.mjs      # 质量闸
```

`verify_surfaces.mjs` 断言（亮/暗各一遍）：

1. 侧栏 vs 主区 ≥ **5.0**（暗色 ≥ 1.10）
2. 卡片 vs 主区 ≥ **1.05**
3. 顶栏 / 标签栏 与主区 **不同色**
4. 菜单文字 vs 侧栏 ≥ **4.5**
5. `--border-strong` 已定义
